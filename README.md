# nexo-gestion
Aplicación de escritorio desarrollada en Python para la gestión de productos, inventario y ventas de pequeños negocios. Utiliza SQLite y ttkbootstrap. Proyecto personal en desarrollo, orientado al aprendizaje y la mejora continua.
Tecnologías

Python

SQLite

Tkinter / ttkbootstrap

Funcionalidades

Gestión de productos e inventario.

Control de stock.

Registro e historial de ventas.

Generación de comprobantes en PDF.

Estado del proyecto

En desarrollo. Continúo trabajando en nuevas funcionalidades, mejoras de diseño y corrección de errores.

Objetivo

Aplicar y fortalecer mis conocimientos de Python mediante el desarrollo de una herramienta práctica para pequeños comercios.
